# Formwheel Story — The Orbit Chronicles

A mystery story integrated with the Formwheel universe. The chosen difficulty is **B — Mystery Exploration**.

## Chapter 0: The First Spin

- Signal transmission and identity selection: ECHO, NOVA, VOID, RIFT
- A story-only first spin and a clue puzzle with three hints
- Chapter completion screen and Quiz link
- Browser-local save (localStorage) and reset
- Mobile-responsive Orbit theme

## Run

Open `index.html` in a browser. For publication, enable **Settings → Pages → Deploy from a branch → main / (root)** in GitHub.

## Planned integration

- Shared Formwheel ID authentication
- Server-verified AQS quests, XP, and achievements
- Quiz ECHO special room integration
- Shared Hub branding and story entry point

**Important:** Chapter 0 currently does not award real AQS XP or badges; identity and completion are local to the browser.
